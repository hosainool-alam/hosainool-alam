## 📂 Featured Projects

### 1️⃣ Telecom Ticket Analysis Dashboard

📊 An interactive dashboard to analyze telecom customer support performance.

- Analyzed 1,000 expected ticket records (final dataset: 850 records).
- Designed a data model using Fact and Dimension tables.
- Created KPIs for ticket volume, resolution time, SLA breaches, and CSAT.
- Developed monthly trends and interactive dashboard filters.

**Tools:** Excel | Power Query | Power Pivot | DAX

### 2️⃣ Sales Data Analysis Dashboard

📈 A business-focused dashboard to monitor sales performance.

- Analyzed sales data using 15 business measures.
- Developed KPI cards and interactive charts.
- Explored sales trends and business performance.
- Presented insights through an interactive dashboard.

**Tools:** Power BI | DAX | Data Visualization

### 3️⃣ Customer Churn Analysis

🔍 An analytical project focused on understanding customer attrition in a subscription-based business.

- Explored customer churn patterns.
- Identified potential factors affecting customer retention.
- Focused on customer behavior and retention insights.

**Tools:** SQL | Python | Excel | Power BI
